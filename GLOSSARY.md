# Context Bridge

Shared vocabulary for collecting developer and project context for AI coding assistants.

## Language

**Developer profile**:
A developer's skills, experience, and learning preferences, shared across that developer's projects.
_Avoid_: Project profile, user account

**Project context**:
A project's goals, domain rules, requirements, and acceptance criteria.
_Avoid_: Developer profile

**Repository context**:
Information obtained from a selected project repository that describes its contents and state.
_Avoid_: Developer profile

**Self-reported skill**:
A developer's own statement of their proficiency in a topic.
_Avoid_: Verified skill, demonstrated mastery
